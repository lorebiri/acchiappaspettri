# What's new (English)

English version of the published releases in [CHANGELOG.md](CHANGELOG.md), used by the English page of the website (`scarica/en/`). Only stable versions are listed here; when a version is not translated, the website shows the Italian text.

## 3.1.0-rc.1 — 19 November 2026

Test version (pre-release): it is not offered as an automatic update. The website shows only published versions.

- XRF, 3.1 model (default for new analyses): peaks with tails and step (hypermet), detector Kα and Kβ escapes for all lines, optional sum peaks, free or fixed noise and Fano, quadratic energy term, Levenberg–Marquardt; tube spectrum after Ebel (1999) with configurable anode, kV, angles and window; fit weights that stay correct with few counts per channel. Settings and projects saved with 3.0 keep the 3.0 model and the same numbers, with a note.
- XRF, element check: a proposed element enters the calculation only if its analytical line is significant and it really improves the fit; removed elements are listed.
- XRF files: `.cfg` fit settings imported and exported; exports of portable instruments read with calibration and live time; SPEC-format `.mca`.
- Raman: where the iterative polynomial would remove too much signal under strong fluorescence, the assistant suggests SNIP or ALS.
- LIBS: calibration-free analysis (CF-LIBS), experimental and tested only on synthetic spectra. The NIST atomic data are not included: they are fetched once from the NIST website from the CF-LIBS panel and stay saved.
- Fixes from an independent review: listed in DEBUG-3.1-INDIPENDENTE.md (Italian).

## 3.0.0 — 18 November 2026

Version released for everyone. Coming from 2.2, you will find:

- Peaks by position: in the Peaks tab, «Add peaks by position» accepts one or more positions in axis units (cm⁻¹, nm, eV, 2θ, minutes…), separated by «;», by a comma and a space or one per line, with optional width (FWHM) and shape (Gaussian, Lorentzian, pseudo-Voigt) for all of them or next to each one (`1086 w=8 lor`). Optional snapping to the nearest local maximum within a tolerance; a preview shows how the text was understood; duplicates, positions outside the spectrum and ambiguous numbers are flagged. The peaks behave like the automatic ones (names, areas, deconvolution, quantification); width and shape are the starting point of the deconvolution. They can be edited (✎) and removed from the table, Ctrl+Z undoes, everything is saved in the project and the note goes into the peak CSV.
- Background removal: new methods ALS (Eilers & Boelens 2005), IModPoly and ModPoly (Zhao 2007; Lieber & Mahadevan-Jansen 2003), rolling ball (Kneen & Annegarn 1996) and anchor points chosen on the plot or typed (PCHIP or straight lines), in addition to arPLS, SNIP (now also for Raman), convex hull and straight line. «Background removal» panel in Adjust the spectrum: adjustable parameters with a live preview of the spectrum before correction and of the estimated background, suggested values computed from the spectrum, scope (all spectra of the technique or only this one), «Apply to all loaded spectra», undo, «Restore the original». The order of operations (cosmic rays → smoothing → background → peaks → areas and quantification) is written in the panel, which follows the same order. Method and parameters are saved in the project; traceability and the methods draft report the parameters used and the references. Validation on synthetic Raman spectra in docs/VALIDAZIONE.md (R12).
- Desktop status bar: the processing chain shows the background chosen for the single spectrum.
- Raman: when the background is strong, the assistant now suggests the iterative polynomial IModPoly instead of arPLS, more accurate on clean spectra with steep fluorescence (docs/VALIDAZIONE.md, R12). Automatic arPLS is unchanged, so saved projects give the same numbers.
- Security and robustness: a hostile project can no longer exhaust memory (bytes counted during decompression; 4 GB limit in the desktop app and 1 GB online, with a clear message); no Excel formulas from file text in the CSVs of libraries and adsorption; tighter permissions on desktop files.
- Fixes from testing: a .acchlib library dragged together with spectra is imported; Settings button visible on narrow screens; methods draft entirely in English; long warnings shortened.
- Presentation and download website (https://lorebiri.github.io/acchiappaspettri/scarica/, in Italian and English): what it is, online or desktop, techniques and formats, features with real screenshots, reliability, all packages with size and SHA-256 fingerprint, instructions for security warnings, frequently asked questions. The online app stays at its address. From the app: About → «Program website»; in the desktop also Help → «Acchiappaspettri website».
- Desktop, fast plot (I6): min/max index and WebGL traces, falling back to Canvas 2D; while zooming and panning only the plot is redrawn; extra «Detach» and «Comparison» windows; menus with all shortcuts; settings on file; XRF/NMR/EPR checks in the worker; XRF beyond 200 000 channels with a warning, estimated time and cancellable computation.
- Professional desktop: sober wording, as in scientific software, without mascot, emoji, exclamations or confetti; its own What's new; no references to the browser. The online version does not change.
- New Export window: choose the items (PDF, PNG and SVG images, peaks, processed data, original data in the order and with the values of the file, identical copy of the original file, analysis tables, traceability, Origin, project), the name of each file and the spectra included. In the desktop app the files go to the chosen folder, also in a subfolder; if a file already exists you choose for each one whether to replace, rename or skip it (or for all remaining ones); at the end a summary with the files written, those not written and «Show in folder». ZIP only if you ask for it; online it is offered above 3 files. Names always valid on Windows, with a warning. Quick export of one item from the menus. Presets also remember the items.
- Projects: format 2 (.acchspettri). The bytes of each original file are saved only once, with room for channels (sampleKey), embedded libraries, spectrum series, maps and isotherms. Version 1 projects open without losses; those saved with 3.0.0 ask 2.2.0 to update. Desktop: settings, library and work are saved to files in the app folder, with atomic writing and automatic migration from the old storage. Name library: the peaks of a reopened project show the right name even when an entry comes in with another code (conflict or long code).
- Help → Report a problem…: prepares in your mail program a message for the developer with technical data, the latest errors and a screenshot you can mask; on Windows the screenshot is already attached. The program sends nothing by itself and does not include spectrum data or file names without your consent.
- Multichannel HPLC: all channels of ChemStation/OpenLab (.ch, .uv, CSV in columns or blocks), Waters .arw and Shimadzu (several blocks and several samples); «Channels found» window with samples × channels, one chromatogram per channel, each file saved once in the project. In the desktop, instrument files open with a double click and «Open with».
- Peak libraries per instrument and sample type: one library for each pair, with name, instrument, sample type, methods, date and author; .acchlib files to import and export (.acchlib.json files are read too), also in shared folders, with a double click. For HPLC each entry keeps the calibration (slope, intercept, range, LOD, LOQ, date and batch) and the concentration is computed without redoing the line, with the origin next to each number; without a check of the day the result says so. The instrument is recognised from the file header. Control chart, system suitability and maintenance in the library. No library is installed by default.
- Analysis → Multiple samples: spectrum series over time, with dose or with temperature; MCR-ALS (SIMPLISMA, EFA, non-negativity, closure, unimodality, known spectra, MCR-BANDS) and global kinetic fit (order 0, 1 and 2, A → B → C, A ⇌ B, parallel), with standard errors, correlations, residuals and AIC/BIC/F comparison. Results in the analysis tables and in the PDF; settings in the project.
- Desktop: files are read in a separate process, with a fast native reader that gives the same numbers as the reference reader (Agilent .ch, Waters .arw, Shimadzu, text files); if it fails, the reference reader is used. Dragging large files no longer copies them into memory and reading can be cancelled. Very large files: 1 million points from click to plot in about 1 s instead of many minutes (linear derivative, smoothing and peak search; identical numbers or within 1e-12 of the scale). The data check is computed in a separate process right after the plot, without freezing the window.
- Desktop: peak search on large spectra and project saving in the native reader, with numbers bit-for-bit identical to the reference ones (saving a 70 MB project in about half the time); deconvolution, multi-spectrum fit and XRF estimates in a separate process, without freezing the window.
- Extensions for new formats (.acchplugin): declarative readers without code (recommended), WebAssembly and JavaScript modules, all isolated with no network and no access to data. Before installing you see author, permissions, SHA-256 fingerprint and the result of the check on the example files; if an example does not match, the extension is not installed. Adjustable file size limit. The project remembers which extension read each file and keeps its bytes if the extension is missing. Three examples and a guide in docs/ESTENSIONI.md.
- Physisorption and chemisorption (Anton Paar Autosorb, Kaomi also in XLSX, ASiQwin, AIF): isotherms with both branches, BET with the Rouquerol criteria (ISO 9277), Langmuir, pore volume, t-plot and αs, BJH and Dollimore–Heal, DR and DA, isosteric heat, DFT with your own kernel; TPR/TPO/TPD with Kissinger and Redhead, pulses, static chemisorption, dispersion and metal area; guided import when the columns are uncertain; settings saved in the project; results in the CSV and in the PDF.
- Origin projects: .opju files (checked on format 4.3721) and .opj files open; a window lists the X/Y pairs with sheet names, long name, units and comments, and you choose which ones to import. Values identical to the original; what is not recognised (text, matrices, derived curves, unrecognised variants) is rejected with a message. The project keeps the Origin file only once. Export to .opj/.opju, not yet checked in Origin.
- Desktop: «Add spectra» and all file choices use the system dialogs (before, on Windows the window froze); dialogs open in the last folder used for spectra, projects and exports, otherwise in Documents; export confirms only after writing the file; native drag and drop of files and folders; window shown already drawn; Analysis → Presets opens the right section. The same file loaded twice at once is added only once.
- Import: an axis with the thousands separator and all values ≥ 1000 («1,100» with a decimal-point Y) gives ⛔; a time or spectral axis that goes back from the same point is read as two blocks; XRF .mca with negative energy in the calibration read in full.
- HPLC: warnings for two signals with a single block and for a channel whose name differs from the header; equal names told apart by the folder; summary tables not counted as channels; tailing factor > 2 even with a single peak. CSV: names from the personal library no longer listed as suggestions.
- Trend: the x unit also in the slope of the CSV. Mandel row, page numbers, confidence intervals in the CSV, warning with LOD = 0, S/N, theoretical plates and summary corrected in English; singular warnings.
- EPR: background zones chosen for the double integral, with their origin in the results; warning when the wings of the line enter the baseline; no false ⛔ with a curved baseline. NMR: warning on the negative peak, «2H» in the name is no longer deuterium, negative scale for δ = σref − σ, warning on stick spectra.
- XRF: As/Pb warning with few counts; texts translated; the warnings of the estimate stay flagged in the CSV and in the desktop.
- PDF: cm⁻¹, ∞ and √ readable; Unicode font loaded only when needed. Chinese, Japanese and Korean titles and names readable with the WenQuanYi Micro Hei font (Apache 2.0), also loaded only when needed.
- Interface: «Data check» section with a single name; warnings, file names and channel menus readable on narrow screens; Export summary complete at 720 px. Projects: library entries are no longer duplicated at every reopening; an intact project with unreadable spectra is no longer called damaged.
- Release: page with the file to download at the top and instructions for Edge, SmartScreen, Smart App Control and Avast/AVG; .deb packages of test versions sorted before the stable one; licences also in .txt.

## 2.2.0

- Acchiappaspettri Desktop for Windows, macOS and Linux: it works offline and tells you when a new version is out.
- New .acchspettri project format: original data, work done and results in a single file, checked at every opening.
- Full interface also in English, dark theme, all resources included to work offline.
- XRF: Kβ energies from the FP tables corrected for Z ≥ 50 (Ba and Sb were strongly underestimated); an incomplete standard is now ignored with a warning. HPLC: theoretical plates corrected on wide peaks, S/N according to the pharmacopoeia (2H/h). EPR: double integral no longer altered by background drift. DSC: undeclared time unit recognised from the plausible rate. Details in docs/SCIENZA.md.
- Desktop app with its own workspace: native menus, toolbar, documents (plot, data sheet, multiple samples), results under the plot, properties on the right, status bar with the processing chain. The online page stays guided.
- Import: warning for unread rows and thousands separators. JCAMP with an axis in Hz converted to ppm with the observation frequency.
- X axis with scale and shift per spectrum (NMR reference, computed frequencies), reported in the methods; axis labels per spectrum.
- New warnings: LOD higher than the lowest standards, signals below the threshold, ignored columns, elements considered and overlapping lines in FP concentrations.
- Lighter online version: study functions (calibrations, PCA, mixtures, XRF composition, false colours) open with «Show here»; peaks and assignments identical to the desktop.
- More cautious hypotheses: a single band or line is inconclusive; coincident XRF lines declared indistinguishable; shared bands declared; «Accept suggestions» does not change the outcome; no element proposed if the XRF axis is shifted.
- Security: jsPDF updated from 2.5.1 to 4.2.1 (fixes known vulnerabilities, two of them critical); PDFs identical to before, also tested with hostile titles and projects.
- HPLC with several channels: channel recognised from the file name (DAD, VWD, FLD, UV_VIS, Ch1, Sig=254, «254 nm»); in «Multiple samples» the calibration uses one channel at a time, with a warning if channels are mixed; channel in the PDF and in the CSV. Name library: deletion with confirmation, entries with the same code merged. Waters .arw files accepted.
- Calibrations: weighted lines 1/x and 1/x², roles standard, blank and control with recovery, status of each estimate (extrapolated, < LOD, < LOQ, clipped top, coeluted, edges, shifted peak, normalised, missing unit) also in the CSV and in the PDF.
- Standardless XRF: each estimate labelled as not validated, conditions in the exported files, primary filter, sensitivity interval to the assumptions.
- Import: data blocks recognised (tables excluded, pauses joined), empty cells, Y column chosen by name, CSV with quotes, unreadable XRF channels, memory tied to the file fingerprint.
- Traceability: `tracciabilita.csv` in every exported folder; processing per single spectrum; computed data can be declared; local recovery copy.
- Security: a project can no longer run code in the page; «Sober» no longer discards spectra.
- Trend: in «Multiple samples» a band measurement can be followed over time or with dose (x with its unit, slope only descriptive, «Trend» page in the PDF); recipes «How degraded is it?» (carbonyl index) and «How yellowed is it?» (absorbance at 420 nm). The methods draft describes the band measurements.
- HPLC: profile of each sample compared with that of the standards (tailing, coeluted or impurity); shoulder warning without false alarms on tails; saturated tops recognised; baseline drifts at the edges of the zone.
- Technique recognised from headers: time in minutes with the detector signal (HPLC even if it does not start at 0), mass in percent (TGA), time and temperature (to be chosen), gradient column «B (%)» not mistaken for an EPR field.
- Hand-typed numbers checked: a single decimal separator; thousands, spaces, text and ambiguous values («1.000») rejected with a warning, never truncated. Band limits outside the axis rejected.
- Serious data problems (⛔) visible under the plot, in the status bar and next to the name; status bar warnings coloured.
- Fixes made before release, after the tests on the test versions:
  - HPLC: the channel comes from the block or column actually read, and the warning says which channel was read; files without a recognisable channel are named and assigned by hand; «DAD1A», «DAD1A_254nm» and «DAD1 A, Sig=254» are the same channel; files with the same name (.D folders) show the folder.
  - Import: two data blocks with no text in between (empty row, or the axis starting again) are no longer joined: one block is read and the other is flagged.
  - Warnings: the most serious one wins and a ⛔ is never hidden; they close with × or Esc; in the desktop the import note shows ⛔ and ⚠, and the ⛔ stays in the status bar.
  - EPR: ⛔ if there is still signal at the ends of the spectrum or if the double integral is negative; MWFQ frequency with a decimal comma; undeclared field unit inferred on the most intense line; warning when values are divided by 10; «Double or single integral» column.
  - Exports: quick CSVs with the separator of the language; no Excel formulas from titles; numbers without thousands separator in parametri_per_tecnica.csv; in the PDF apostrophes, quotes, €, •, ‰, ², ³ correct and full title in the metadata.
  - FTIR in transmittance 0–1: no wrong index, «transmittance read as absorbance» warning; an absorbance with a high background stays absorbance (the column name or the shape of the spectrum decides).
  - Interface: in the desktop «Download» always visible; calibration tables fit in the panel; What's new translated into English also in the desktop; «> 100,000» with the format of the language.
  - XRF: silver alloy measured with a silver tube estimated correctly (silver from the Lα line, with a warning); with few counts a line counts only above the Currie limit and the signal-to-noise ratio is realistic; pure tin no longer declared with a shifted axis; CSV of the FP estimate with correct and translated notes; FP table readable in the desktop panel.
  - One million points: no more blank plot or system error.
  - Release: the AppImage tools are always checked against the hash published by GitHub; the release page says which file to download and how to get past the Windows and macOS warnings.
